# RDP عبر GitHub Actions وTailscale

> **تنبيه:** هذا المستودع يحتوي ملفات سير عمل GitHub Actions فقط، وليس تطبيقًا أو برنامجًا مستقلًا لإدارة سطح المكتب البعيد. المراجعة هنا ساكنة؛ لم يُشغّل أي سير عمل أو كود ولم تُجرّب خطوات الإعداد.

## نظرة عامة

يحتوي المستودع سيرَي عمل متقاربين (`.github/workflows/main.yml` و`main.yml`) يبدآن يدويًا عبر `workflow_dispatch`. وفق ما هو مكتوب فيهما، يحاول سير العمل إعداد مضيف Windows مستضاف من GitHub، تفعيل اتصالات RDP، تثبيت Tailscale والانضمام إلى شبكة Tailscale، فحص إمكانية الوصول إلى TCP/3389، ثم إبقاء المهمة قيد التشغيل في حلقة انتظار.

وجود هذه الخطوات في الملفات لا يثبت نجاح الاتصال أو صلاحية الاستخدام، ولا يعني أن الإعداد آمن. الملفان متشابهان لكنهما غير متطابقين؛ لا توجد حاليًا نقطة تشغيل موحّدة أو وثائق أصلية أخرى توضّح أيهما المعتمد.

## ما يتضمنه المستودع

- `.github/workflows/main.yml` — سير عمل GitHub Actions يدوي على عامل Windows.
- `main.yml` — نسخة أخرى متقاربة من سير العمل.

لا يظهر في الملفات المفحوصة تطبيق RDP مستقل، أو اختبارات، أو ملف متطلبات لتثبيت اعتماديات مشروع. ولا يوجد README سابق أو ملف ترخيص في المستودع.

## المتطلبات والإعداد الظاهر في الملفات

الآتي وصف لما تشير إليه ملفات سير العمل، وليس إرشادات تشغيل موصى بها قبل معالجة المخاطر أدناه:

- مستودع GitHub مع تفعيل GitHub Actions وإمكانية تشغيل سير العمل يدويًا.
- عامل GitHub Actions يعمل بنظام Windows، كما هو محدد في الملفين.
- حساب Tailscale ومفتاح مصادقة محفوظ في GitHub Actions Secrets بالاسم `TAILSCALE_AUTH_KEY`.
- اتصال الشبكة اللازم لتنزيل مُثبّت Tailscale والوصول إلى شبكة Tailscale.

## التشغيل كما تصفه الملفات

سير العمل مُعدّ للتشغيل اليدوي من واجهة GitHub Actions (`workflow_dispatch`). تتضمن خطواته تهيئة Windows وتثبيت Tailscale والتحقق من اتصال TCP إلى المنفذ 3389، ثم تكرار الانتظار إلى أن يُنهى تشغيل المهمة أو تنتهي مهلتها.

**هذه الخطوات غير مجرّبة. لا تشغّل أيًا من الملفين بصورته الحالية.** لا يقدم المستودع إجراءً موثوقًا أو آمنًا لإنشاء جلسة RDP؛ ينبغي معالجة الثغرات وتوحيد الملفين ومراجعة الإعدادات قبل التفكير في أي تشغيل.

## تحذير أمني

تحتوي ملفات سير العمل على إعدادات عالية الخطورة، منها بيانات اعتماد محلية ثابتة، وإظهار معلومات دخول وعنوان اتصال في سجلات التشغيل، وإنشاء حساب ذي صلاحيات إدارية، وفتح المنفذ 3389 على جدار الحماية دون تقييد واضح إلى واجهة Tailscale. كما تعطل الإعدادات الحالية مصادقة مستوى الشبكة وطبقة أمان RDP. وجود سر Tailscale ضمن إعداد GitHub لا يعالج هذه المخاطر، وقد يؤدي تشغيل سير العمل إلى كشف المضيف أو بيانات اعتماده.

لا تستخدم هذه الملفات للوصول إلى أنظمة أو شبكات دون تصريح صريح. قبل أي استخدام، أزل بيانات الاعتماد الثابتة ومخرجاتها، ودوّر أي بيانات اعتماد سبق أن استُخدمت أو كُشفت، وفعّل مصادقة RDP وطبقات الأمان، وقيّد قواعد الجدار الناري إلى مصادر موثوقة، وطبّق أقل الصلاحيات، وأضف تنظيفًا وإنهاءً واضحين. لا تضع كلمات مرور أو مفاتيح أو عناوين اتصال حساسة في الشيفرة أو السجلات.

## الحدود والحالة

- لا تؤكد القراءة الساكنة أن إعداد Windows أو Tailscale أو اتصال RDP سيعمل.
- الملفان متقاربان وغير متطابقين؛ قد ينتج عن ذلك سلوك مختلف، ويلزم تحديد ملف واحد معتمد.
- مهمة التشغيل محددة بمهلة طويلة وتحتوي حلقة انتظار، ما قد يطيل مدة التعرض واستهلاك عامل Actions.
- لا توجد اختبارات أو تعليمات استعادة/تنظيف موثقة في الملفات المفحوصة.
- لم يُعثر على ملف ترخيص؛ لذلك لا يُفترض وجود ترخيص أو تُمنح أذونات استخدام إضافية.
